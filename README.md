# rWebRouter

Every link opens in the right browser: ordered rules send each link to the browser, or the Chrome or Firefox
profile, it belongs in, on iPhone, Mac and Linux.

- Website (canonical): https://webrouter.radut.dev
- Downloads: Mac and Linux coming soon (they will be published as releases of this repository); iPhone coming soon.
- This repository holds only a generated copy of the website (served at https://radut.github.io/rwebrouter/) and the releases.
  Questions and requests: [issues](https://github.com/radut/rwebrouter/issues).
