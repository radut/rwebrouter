How it works

Your rules, checked in order.

Make rWebRouter the default browser once. From then on every link you click, in mail, chat or a terminal, goes through your rules, and the first rule that matches picks the browser.

1

A link arrives

You click a link anywhere. The system hands it to rWebRouter, the default browser.

2

Rules decide

Rules are checked top to bottom. Disabled rules, and rules whose browser is missing here, are skipped.

3

The browser opens it

The link opens in the chosen browser, in the right Chrome, Edge, Brave or Firefox profile.

4

No match, no surprise

Links that match no rule go to the browser you pick for that. On iPhone they can open right in the app.

Example: work in Chrome, the rest in Firefox

  1. 1Work sitesApplies to*.work.example, tickets.example.com→ Chrome – Work
  2. 2Video callsApplies tomeet*.example.org→ Chrome
  3. 3Everything elseDoes not apply to*.work.example→ Firefox – Personal
  4. ·Links that match no rulethe fallback browser→ Firefox

A rule applies to the links its entries match, or, set to does not apply to, to every link except those. Any one entry matching counts.

What an entry can match

KindExampleMatches
Domain and subdomains*.work.examplework.example and every subdomain
Host istickets.example.comexactly that host
Host wildcardmeet*.example.orghosts matching * and ?
URL containsexample.com/docs/teamany link containing the text
URL regex^https://[a-z]+\.example\.net/a regular expression on the full link

All case-insensitive. Only web links (http, https) are routed.

Platforms

One config, three platforms.

The iPhone, Mac and Linux apps read the same JSON file. Export it on one, import it on the others: a “Chrome – Work” rule opens the work profile on the Mac and on Linux, and Chrome on the phone.

A menu-bar router for macOS 15+

No window of its own: it sits in the menu bar and passes links on. Hold ⌥Option while clicking a link to pick the browser yourself.

  1. Open the zip and move rWebRouter to Applications, then start it. The app is signed with Developer ID and notarized by Apple.
  2. Settings → General → Links on this Mac open with: rWebRouter. macOS asks you to confirm.
  3. Browsers → + lists every installed browser and its profiles; click Add on the ones you route to.
  4. Rules → +: add your rules, drag to reorder, right-click a rule to add its opposite.
  5. Test: type a link and see which rule and browser take it.

A desktop-entry router for Linux

rwebrouter is registered as the default browser and starts the browser the rules choose, with --profile-directory for Chromium browsers and -P for Firefox. rWebRouter Settings (GTK 4) edits the rules.

  1. Install the .deb: sudo apt install ./rwebrouter_1.0.0_amd64.deb
  2. rWebRouter Settings → General → Make default, or rwebrouter make-default.
  3. Browsers → Add browser finds installed browsers (deb, snap, flatpak) and their profiles.
  4. Rules → +, then Test shows the exact command a link would run.

A small browser that routes, for iOS & iPadOS 18+

On iPhone rWebRouter is a real browser too: pages open right in the app, and rules send chosen sites to Chrome, Firefox, Edge, Brave, DuckDuckGo, Opera or any app you add. Coming soon.

  1. Settings → Rules → +: what to match, where to open it, and a live test.
  2. Links that match no rule: open here, or send them to another browser.
  3. Share a link to rWebRouter from any app to route it.
  4. Once Apple grants the default-browser entitlement: Settings → Apps → Default Browser App → rWebRouter.

How to

Set it up in five minutes.

The common setups, step by step. Every screen on this page shows demo data only.

Send work links to a Chrome profile

  1. Browsers → + (Mac) or Add browser (Linux): click Add next to Chrome – Work.
  2. Rules → +: name it “Work sites”, Applies to, entry Domain and subdomains *.work.example.
  3. Add more entries with + (e.g. Host is tickets.example.com); any one matching counts.
  4. Open in: Chrome – Work. Save.

Everything else to Firefox

  1. Right-click the work rule → Add the opposite rule (Mac), or add a rule set to Does not apply to *.work.example.
  2. Open in: Firefox – Personal. Keep it below the work rule.
  3. Or simply set General → Links that match no rule to Firefox.

Make it the default browser

  1. Mac: Settings → General → Links on this Mac open with → rWebRouter.
  2. Linux: Settings → General → Make default, or rwebrouter make-default.
  3. iPhone (when available): Settings → Apps → Default Browser App → rWebRouter.

Use the same rules everywhere

  1. General → Export… saves router-config.json.
  2. Move it by AirDrop, Files, a USB stick or any sync folder.
  3. General → Import… on the other device. Each platform keeps its own fallback browser in the same file.

Pick the browser for one link

  1. On the Mac hold ⌥Option while you click the link.
  2. A chooser lists your browsers: press 1…9 or click one; Esc cancels.

Check where a link would go

  1. Test tab on Mac and Linux: type a link, see the rule and the browser.
  2. On Linux also from a shell: rwebrouter test https://example.com.

FAQ

Questions.

Can rWebRouter be the default browser on iPhone?

Only apps Apple grants the default-browser entitlement can be picked under Settings → Apps → Default Browser App. rWebRouter has requested it. Until then you can share links to it, or open them in it.

When is the iPhone app available?

Coming soon.

Is the Mac app a browser?

No. On the Mac it is a menu-bar app with no window: it receives links as the default browser and passes each one to the browser your rules choose. Settings opens from the menu-bar icon or with ⌘,.

Is the Mac app signed?

Yes. The Mac download is signed with Developer ID and notarized by Apple, so it opens like any other app from the internet. Each release lists SHA-256 checksums in SHA256SUMS.

Which Linux systems are supported?

The .deb is for amd64 Ubuntu 24.04, Debian 13 and newer (it needs GTK 4 and libadwaita for the settings app). Browsers installed as deb, snap or flatpak are found. Other packages are not built yet.

Which browsers and profiles work?

Chrome, Chromium, Edge, Brave, Vivaldi, Firefox, Safari, Opera, Zen and Arc, depending on the platform, plus any app that opens web links. Chrome, Edge, Brave and Vivaldi profiles and Firefox profiles are found automatically.

Does rWebRouter send my links anywhere?

No. There is no account and no server: rules and recent links stay on your device, and a link only ever goes to the browser you route it to. See the privacy policy.

How do I move my rules to another device?

General → Export… writes one JSON file; General → Import… on the other device reads it. iPhone, Mac and Linux use the same format.
