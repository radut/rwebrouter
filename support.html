rWebRouter

rWebRouter support

rWebRouter is a free app for iPhone, iPad, Mac and Linux that sends every link to the browser, or browser profile, it belongs in.

Get help

  • Questions, bugs and ideas: open an issue at github.com/radut/rwebrouter/issues. Say which device and version you use (Settings shows the version) and, for a rule problem, the link and the rule.
  • Please do not post private links, passwords or account emails in an issue; replace them with example.com.

Common questions

  • How rules work, the order they apply in, and how to make rWebRouter the default browser: How it works and How to.
  • Answers to frequent questions: FAQ.
  • A rule does not match: use Settings → Test (Mac, Linux) or Try it in the rule editor (iPhone) to see which rule applies to a link.
  • Privacy: privacy policy. Terms: terms of use.
